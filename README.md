# ARNavigation

## 프로젝트 개요
학교 내 건물이 매우 넓고 복잡하여 신입생, 학교 손님, 그리고 다른 건물에서 수업을 들으러 오는 학생들이 원하는 강의실이나 시설을 찾기 어려운 문제를 해결하고자 ARNavigation 프로젝트를 시작하게 되었습니다.

## 프로젝트 설명
**IT융합대학 AR Navigation**은 IT융합대학 건물 내부에서 증강현실(AR) 기술을 활용하여 사용자가 쉽고 빠르게 강의실 및 시설 위치를 찾을 수 있도록 도와주는 모바일 길 안내 서비스입니다.

- AR 기술을 활용해 실제 공간 위에 시각적 길 안내(예: 선, 화살표 등)를 제공합니다.
- 직관적인 UI로 사용자가 층수를 선택하고 원하는 강의실 번호를 선택하면 해당 위치까지의 경로를 AR 화면을 통해 안내합니다.
- 별도의 복잡한 지도 앱 사용 없이도 건물 내부에서 손쉽게 길을 찾을 수 있도록 설계되었습니다.
- Unity 엔진 기반으로 개발되어 다양한 모바일 기기에서 원활하게 동작합니다.

## 주요 기능
- **층별 강의실 목록 제공:** 앱 실행 후 층수를 선택하면 해당 층의 강의실과 주요 시설 목록을 확인할 수 있습니다.
- **AR 길 안내:** 선택한 강의실까지 AR 화면 상에 시각적으로 길 안내를 제공합니다. 사용자는 실제 공간을 보면서 정확한 위치까지 쉽게 이동할 수 있습니다.
- **사용자 친화적 UI:** 간단한 조작만으로 누구나 쉽게 사용할 수 있도록 직관적인 인터페이스를 구현하였습니다.
- **확장 가능성:** 향후 학교 내 다른 건물 및 시설로 확대 적용할 수 있는 구조로 설계되었습니다.

## 사용 기술 스택
- Unity (유니티): AR 기능 구현 및 앱 개발
- AR Foundation / ARKit / ARCore (사용하는 플랫폼에 따라 선택 가능)
- C# (유니티 스크립팅 언어)

## 기대 효과
- 신입생 및 방문객의 강의실 찾기 어려움 해소
- 학교 내부 공간 활용도 및 편의성 향상
- 건물 내 길 안내에 소요되는 시간 단축 및 효율성 증대
- AR 기술을 활용한 혁신적인 사용자 경험 제공

## 향후 계획
- 학교 내 다른 건물 및 외부 공간까지 길 안내 영역 확대
- 실시간 혼잡도 표시 및 경로 최적화 기능 추가
- 사용자 피드백 기반 UI/UX 개선 및 기능 고도화
- 다국어 지원 및 접근성 강화
